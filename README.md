# InterviewIQ 🚀

An AI-powered interview preparation platform that helps students and job seekers practice mock interviews, improve communication skills, and analyze speech confidence in real time.

## 🌐 Live Demo

🔗 https://megainterview.netlify.app/

---

## ✨ Features

- 🎤 AI Speech Analysis
- 📊 Performance Analytics
- 💬 Mock Interview Practice
- 📈 Confidence Score Tracking
- 🧠 Real-time Feedback System
- 📱 Fully Responsive UI
- 🎨 Modern Glassmorphism Design

---

## 🛠️ Built With

- HTML5
- Tailwind CSS
- JavaScript
- Web Speech API

---


## 🎙️ Important

Speech recognition works best in:

- Google Chrome
- HTTPS deployment
- Localhost (Live Server)
